## 本版具体修订

- 对照同一事实的不同所问：能否结婚/结婚日期；六合三个领域分别取用/只问一个领域；本人/代问；出生年未知/已可靠给出；起局年干的字已给/未给；宫本身的五行/宫内符号。每个教师都有具体原文摘录，合成的年干仅为题目明示前提，不是假造历史出生年或反馈。
- 保留完整材料、规则、流程、194案例和1008分析。911条纯原文阅读课独立归档，不参与本轮应用SFT；原书案例复盘、作者局部判断、领域规则与流程继续参与。原文阅读材料仍可查阅和检索，归档不等于删除知识或重置权重。
- 重新实际检索验证40条人物教师。它们与现有对话完全相同，合并检索确认与来源证明，**不重复计数、不重复训练**。18题实际RAG重新构建来源包，逐条检查所需规则可见。
- 知识问答移除通用的“没有本次盘面、不补应期”段落，避免把可从书中解释的条件题误当缺资料的预测题。实际时间起局/程序盘验证仍调用原App代码，模型不计算历法和排盘。
- 每条课记录所问目标、适用检查、具体来源及训练/阅读处置；全部输入与完整答案进行真实分词检查，不靠截断答案满足4096上限。

## 评估修订

冻结V5.7原检查和审阅结果，V5.8在新命名空间修订：

- 接受“归于土”“亦是木”“水。依据…”等明确正确属性，以及前者/后者、A/B、甲方/乙方的明确主客关系；未解释充分与事实错误分开。
- 所有明确结论必须与法则和主客方向一致；“应改受克”后又写“金克木”，或门宫前面比和、后面宫生门，均不能通过。
- 区分起局年干与出生年命；可靠出生年癸不等于本局年干癸；未知出生年不能实际兼用未给的年命。只问主用神时，不强迫复述未问的固定边界句，但真的越界使用未知年命仍失败。
- 数对正确但附加天/地生数成数颠倒，也记录为错误解释；不能只检查首句两个数字。
- 实际RAG引用按具体规则的可替代来源组检查，不机械要求未采用的可选S编号；多个领域的问题必须覆盖相应多个规则组。一般题只证明引用编号存在时明确标注membership范围，不冒充开放语义已验证。
- 80题覆盖25有向五行组合、宫位/整盘关系、门宫命名、属性、已知/未知年命、类型边界、数字及所问范围对照。最后192题保留19个案例来源领域；开放案例须逐题审阅，不以关键词命中自动批准专业成品。

软件反例来自已知错误模式，仅作为检查器回归，不把模型错答加入教师。每项自动检查都有明确范围，不能承诺任意自然中文或所有开放案例语义已经100%自动核准。

保留同级WenguaApp的既有环境和8B缓存，在PowerShell粘贴：

```powershell
Set-Location "$env:USERPROFILE\WenguaQuant"
git pull --ff-only origin main

```
