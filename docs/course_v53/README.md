# V5.3：两书证据应用、初始化对照与实际 RAG

V5.2 的两组训练均完成，但更低语言 loss 没有解决生克方向和跨领域取用。V5.3 先修课程，再以同教材短训比较官方 Qwen3-8B 新建 LoRA 与本机已经完成的 V5.2 权重。旧模型、旧输出及 WenguaApp 的起盘代码全部保留。新增古籍继续暂停。

详细实测依据见 [V5.2 逐轮复查](../model_reviews/20261105_v52/README.md)。本版本不沿用旧人工吉凶分数作答案，也不以模型的错答生成新知识。

## 数据已经如何处理

| 内容 | 数量与用途 |
| --- | --- |
| 原有两书材料 | 7614 单元，原样保留 |
| 补回有精确原文位置的阶段选段 | 194 单元；初断、反馈、补充解释明确分开 |
| 全部原案与已索引分析 | 194 案、1008 条，保留全部目录及原文；测试案例不进入教学 |
| 基础课程 | train 618、validation 618；分别训练记忆与给定证据后的应用 |
| 应用课程 | train 3698、validation 649，另有10道已见诊断 |
| 合计 | 5593 条课程，包含对照问法，不等于5593个独立知识点或案例 |
| 两书 RAG | 43 个完整章节、5320 个来源文档 |

172 条整案证据链课程按阶段提供材料；其中164案明确提供初断选段、171案提供反馈选段。33处书中补充解释或阶段标记被重新定位，其中21条包含明确专业条件，形成解释课程。它们补的是旧1008条分析索引未完整覆盖的原书说明，不是新增真实案例。原167条阶段混杂的摘要目标隔离保留，不直接重播。另有37条更正前的分段分析移出独立教学目标，仍在整案中保留原文、初断与更正标记。书中学员初断与作者更正不能一律当成正确通用规则。少数没有安全完整目标的案例保留为目录/来源，不编答案。

整案复盘会显示原书已经提供的反馈，因此只能评价来源阅读与复盘。它不是让模型在不知道反馈的条件下预测未来。完整作者分析都保留在私有数据库；课程中的阶段摘录只是有来源的选段，不把“已入库”说成每句话都已训练或全部语义已获独立专家批准。

具体修改包括：

- 父亲代儿子考试的参考答案改成实际考生，去除误沿用的“女儿”；父母代问与本人问事分别取用。
- 健康题的年命定义改引一般理论来源，不再借考试章节的操作规则推成通用健康规则。
- 委员、蛋糕、走失侄女等案例，把初断、后续事实和作者纠正分别提供；不要求回答未展示的反馈。
- 两条图名答案、三条夹带案例审计注的旧目标不再充当专业答案。
- 同一原书盘面正反向提问；读宫位、判断五行方向和综合说明分开练，不伪造相似盘为真实案例。
- 正常回答用完整中文，先答当前问题，再解释条件和依据。只答关系词限于明确标注的关系检查小题。
- 给定证据题加入另一条真实但无关的来源，正确来源不总是 S1；不能靠固定引用位置过关。

原最终933条 test 指纹继续封存，不参与本次修题、训练或候选选择。开发题属于已公开诊断；基础定义的 validation 是同知识点的不同问法，不能当成未见知识泛化。

## 自动 loop 实际做什么

1. **准备与核对。** 恢复私有教材、Excel、SQLite及原两书 RAG。固定官方8B修订、r16/alpha32/dropout0.05、q/k/v/o、4096上下文、累积16、梯度检查点、受监督位置分块 loss、已验证的融合注意力路线。
2. **初始化对照。** 官方模型新建 LoRA，不载入 V4/V5.1；若 `local/course_v52/run2/review_nominee.json` 指向完整、可校验的 V5.2 正式权重，则增加继承路线。两者都用同一基础课程、2e-5学习率短训64步。新建路线先做短序列 eager/fused 前向数值核对；不把该核对当作真实GPU已通过。
3. **有限基础补课。** 按相同开发题比较，不按训练 loss 选胜者。若尚未达到基础检查，胜者按原优化器、原两轮学习率计划接至128、最多256步；已经通过就提前进入下一阶段。64/128/256是同一个训练计划中的暂停点，不每次重置学习率。仍未通过则标记 `needs_course_review` 并停止长训，保留全部结果。
4. **应用阶段。** 从选定基础权重分别开始1e-5、2e-5两组，各两轮。换教材建立新优化器；同组两轮连续。每轮同时检查128道来源/盘面/案例题、128道基础回退题和18道实际检索后回答的 RAG 题。
5. **保留与审阅。** 只有通过来源、宫位、方向、基础保留及RAG运行检查的候选才提名审阅。未通过则保留基础候选，不自动把退步的应用模型替换上去。所有开放案例仍需看原答，不会被关键词检查自动批准。

门槛是课程进度检查，不是奇门人工加减分：基础阶段给定证据槽位≥80%、记忆槽位≥50%、五行方向≥80%；应用阶段给定证据≥80%、宫位≥85%、带盘方向≥75%。这些通过数不是完整语义正确率，更不是现实预测概率。没有独立外部真实结果验证。

每个训练/评估单元用独立子进程，退出后释放该进程显存；仍保留实际显存压力测试。原有 bounded loss 与融合注意力路线继续核验，禁止长序列静默退回大显存的数学注意力。训练计划有限，不无限调参。

## RAG 与起盘

RAG 在独立的 `local/rag/two_books_v53_v4.sqlite3` 建索引，不切换旧全局索引。CPU SQLite FTS5 检索保留书名、章节、原文行号及SHA；新增上层/下层到天盘/地盘的查询归一化，以及有上下文的单干检索，避免把“申请”“孩子”误拆成申、子。补入六合等神名的检索特征和买卖/交易领域识别；跨领域问题从各所问领域保留候选。旧索引中一条有明确干对定义和来源标记的参考材料，在新版派生索引中重新归为规则，原文与选择坐标不变，分类更正另存回执。历史案例不能按此途径提升为通用规则。

给定正确原文的课程评估，与实际检索后生成的18题分开记录。检索来源覆盖、引用是否存在、程序盘面是否冲突分别检查；引用有效不代表答案语义正确。`knowledge`/`reading`模式只检索规则，整案与后续反馈只在明确的历史 `study` 模式使用。

按时间起盘继续调用 WenguaApp 现有历法与排盘程序。模型读取程序盘面，不负责算历法、排九宫或编造应期。历法接口需要明确时区以避免错盘；回答本身不插入无关时区套话。

## 在当前 Windows PowerShell 启动

两仓库仍并排放在用户目录，复用已经安装好的 qwen_env 和缓存模型：

```powershell
Set-Location "$env:USERPROFILE\WenguaQuant"
git pull --ff-only origin main
.\train_wengua_v53.cmd
```

第一次恢复输入此前V4/V5.1教材的64位口令，输入可见。不要把ZIP路径当口令，也不用把口令写进命令或Git。恢复成功后不再询问。若Windows缺少历法时区数据，入口只补 `tzdata==2025.2`，不重新安装整套训练环境。

默认结果：`local\course_v53\run1\results.html`。教材审阅表：`local\course_v53_data\Wengua_两书RAG课程_V53_全量审阅.xlsx`；数据库同目录 `Wengua_两书RAG课程_V53.sqlite3`，包含全部课程、来源、194案、1008分析、完整章节及RAG文档。

另有V5.2逐题逐轮Excel：128题八版本对照、全部1458条原答、旧数据问题与每轮数值。它只作审阅，绝不进入RAG知识或SFT教材。需要看完整原答时恢复到独立审阅目录：

```powershell
& ..\WenguaApp\local\qwen_env\Scripts\python.exe -X utf8 -m wengua_course_v53 restore-review
```

使用同一教材口令，输出 `local\reviews\v52_semantic_audit\Wengua_V52_逐题逐轮审核.xlsx`；不加载模型、不改训练运行。

中断后重复启动同一入口，自动查最后完整checkpoint并恢复优化器、scheduler与随机状态。同阶段恢复和跨教材阶段继承权重是两件事；不能用仅有adapter的目录冒充完整checkpoint。需要手工指定时，必须属于当前V5.3运行的最后完整checkpoint：

```powershell
.\train_wengua_v53.cmd --resume-from-checkpoint "C:\Users\wtmas\WenguaQuant\local\course_v53\run1\trials\实际任务目录\cycle_01\trainer\checkpoint-实际步数"
```

代码或教材合同改变时不会静默覆盖旧运行，应保留旧输出并用新 `--output`。正常重复执行已完成的运行只刷新报告，不再训练。

导出审阅ZIP（不含模型与优化器大文件）：

```powershell
$review = Join-Path $env:USERPROFILE ("Downloads\Wengua_V53_review_" + (Get-Date -Format "yyyyMMdd_HHmmss") + ".zip")
& ..\WenguaApp\local\qwen_env\Scripts\python.exe -X utf8 -m wengua_course_v53 export --archive $review
```

## 验证证据与边界

构建后逐项校验SQLite读回、外键、Excel完整对话与答案、原书字符/行号及来源指纹；4682条明确槽位参考答案通过软件检查。实际固定分词器核验5593条完整目标，最长2674 token，无不适配项；开发集还预留1024 token回答预算，不截断来源条件。

192道既有来源问题在前8个检索结果中全部覆盖指定原文行段；18道实际RAG检查题在4096预算、预留1024回答空间后，所需原文全部可见。这是已知题目的来源覆盖检查，不是检索泛化或答案正确率。详见本目录 `build_audit.json`、`token_audit.json`、`rag_retrieval_audit.json`、`rag_prompt_audit.json` 与 `preservation_check.json`。

微型随机CPU Qwen3/PEFT验证新LoRA初始化、起训前权重一致与空优化器、独立进程中断后逐张量恢复相等、训练完但生成未完的恢复路径统一FP32 norm、跨阶段评估、两学习率有限loop、导出与已完成不重训。`cpu_linux_verification.json` 中Windows专属项为false表示该Linux本地检查未执行Windows恢复；Windows工作另执行16MiB公开合成密文的.NET恢复，不使用用户口令。它们验证软件流程，不能替代本机4080的真实8B训练、长上下文数值或专业答题验收。实际结果出来后才评价本版模型是否提升。
