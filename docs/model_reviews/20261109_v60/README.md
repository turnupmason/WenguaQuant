## 评分问题：不是所有“未过”都真错，也不是“通过”就解释全对

原分数保留，独立注释不反写训练器：

- 正确回答A生B、B受生，或从火看木受生、从木看火生，原检查有时未识别反向视角，误当冲突。
- “天地盘同宫资料未给”合称了缺项，原检查却要求分别出现天盘、地盘；“应先明确谁求测”也被固定追问词表漏掉。
- 放贷回答完整引述四个分支，含正确当前凶分支，却因同时引述另一条件下的吉而失败。它仍没有直接选择当前分支，不能简单改为整题优秀，也不应称其每句事实错误。
- state题仅命中“旺/休”就通过，但解释仍会把主动生/克写成受生/受克；一道人物题明说可靠出生年不能兼用，也被判完整。
- 最终定位16/16只说明指定星所在宫均找到；其中一道额外写错宫神。不能把定位通过等同于整段无错。
- 官方24题控制的原检查7/24、父权重13/24，受Markdown、标题行和引用格式影响；官方还6次耗尽512token。读答发现官方河图数和若干属性其实正确，因此不凭这张小套汇总就宣布旧adapter全面优于官方。两者也都有真实关系错误。

以后应把所问结论、角色与方向、必要条件、解释中的附加主张、引用对应、输出完整性分别验收。不能只检查正确词出现，也不能为通过已见答案而改宽门槛。

## 192题的案例及作者分析：能读资料，尚未学会稳定组织整案

最终192含21份案例复盘、40份作者步骤、16定位、29其他宫位关系，以及人物、条件、领域规则和流程。只这一候选有该套结果，**没有整案进步的配对测量**。

- 多数单步作者题能复述原段，疾病A/B两个病例也能保留各自年龄、内外盘、月令和年命区别；一些工作、诉讼、天气和婚姻规则能准确读取。
- 案例题仍经常只摘一条结论，或把结论原样再抄成依据，而没有组织用神—宫位—条件—判断。升职失败案能分先断与后来未成，但事后解释只剩谨慎口号，漏门迫、死绝、空亡等纠错依据。
- 婚姻案把后来的离婚反馈写成作者分析并绑错引用；多盘选举题未说明不同盘次。引用编号有效只证明编号存在，不证明每句话被对应原段支持。
- 一份考试复盘同段重复五次；一份人生案例同句重复四次，虽未达到冻结五次阈值仍不可用。另一本来只给出生叙述的题，编造多年升学履历并重复至768token上限。
- 天气反例问“不乘壬癸是否仍下雨”，回答漏关键前提；讨债题能答角色却漏本息追回组合；天心/乙奇同宫题只答不等同，未说明星与干分别按哪些规则判断力量。

这些是来源学习与条件应用问题，不是独立现实事件预测成绩。

## 课程根因：原文没错，不等于问答制作已经合格

这次课程仍有需要修正的工程缺口。之前的完整来源、行号、哈希、token长度和有限关键词检查，**没有充分验收“问题实际问什么、答案是否正面回应、每一步如何使用条件”**。不能把这些验收通过说成课程语义百分百正确，也不能把失败归给用户提供的书不够。

1. **不同任务仍混用摘抄教师。** 天心与乙奇同宫题要求解释层次和力量，教师却是数段竖看、旺衰与疾病原文；完整原文应当保留为依据，教师另用正常中文明确回答具体区别。该题有train版本，但本次768短训没抽到；不能说本次已训练过所有已发现问题。
2. **案例问题很宽，目标选择却没有交代。** 部分题给整案很多步骤，只泛问复盘，教师挑两步。模型选其他有依据的步骤不能一律判错，但也学不到完整整盘分析的明确目标。应按阶段和所问子目标重新切题，完整案例再显式要求覆盖主要判断、支持/反证和反馈边界。
3. **样本数平衡掩盖了输出token配比。** 用同一官方tokenizer重新核算，本次768核心/786视图有59,548个监督token；作者步骤、案例复盘、领域原段及流程合计40,325，约67.7%。这是文字配比，不是精确梯度贡献，但说明多数监督仍花在复述来源。852作者课程中613条目标就是完整可见步骤的逐字复制。全部有来源仍不能证明学到了新盘推理。
4. **条件对照有了，密度仍不足。** 本次混合短训有108个condition核心，其中10个是新建的双向多轮对照；不是只有10条条件教学。它们只是786监督视图的一部分，不能预期50步混合更新就完成多领域条件推理。实际仍出现条件一换答案不换。
5. **叙述材料仍误用分析任务名。** 作者步骤筛选的“生”等字命中出生叙述，把纯履历纳入作者判断题。这次发现的是validation中的具体一条，不说成所有train同错；原文和案例必须保留，教学类型应改成有明确目标的事实摘录或阅读。

验证loss采用教师给定正确前缀后的逐token预测；关键关系词只有少数token，后面大量固定结构与引用仍易预测。所以关系题loss很低，也可以在自由回答的第一处方向选择上出错。不能以更低loss替代上述逐项核对。

## 下一轮的明确顺序

保留V5.8与全部V6.0候选，先不延长这份混合教材训练，也不自动从失败候选接长训。下一版应先完成三项可检查的工作：

1. 逐项重写任务教师：明确所问、当前主体、给定事实、适用规则和直接结论；原文放证据区，答案用二至五句正常中文解释。宽泛整案按明确目标拆分，完整复盘保留支持、反证和反馈边界，叙述材料另分类。
2. 固定小套必须核对结论与解释一致、条件切换及附加主张，保留正常同义和反向视角；对已有正误反例先做独立软件检查，新题与旧回归分开。已见832条仅作评估，不直接回灌教师或RAG。
3. 再做一次小规模分阶段对照，先学明确的事实绑定和条件选择，再加入案例综合；按监督token控制各任务占比。旧adapter保留作对照，若比较官方新LoRA也使用同一份修订小教材和同预算，先比较再决定继承路径，不盲目重训整套基座。

WenguaApp原有历法、起盘与可确定计算继续保留为事实来源；RAG继续提供原书证据。新古籍没有热加到本轮，不能用它们替代本次课程目标和回答组织的修复。本次审阅没有改旧课程、运行合同、App起盘、RAG指针或权重，也未发布下一版训练入口。
