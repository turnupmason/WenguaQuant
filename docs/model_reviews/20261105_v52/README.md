## 课程与评估仍有漏检

前次课程审阅不充分；以下问题属于数据制作或评估合同，不能一概归给模型。

1. **人物不一致**：开发题问父亲代儿子考试，参考答案沿用“女儿”。时干规则仍有原书支持，但该参考句必须改成儿子/考生，不能为了保留旧模板忽略对象。
2. **最初分析与后来复盘混在目标**：委员案输入仅三段最初有利分析，目标却要求后来未补选和失败反思；没有把后续材料提供给模型。正面初断不应仅因未补说后来失败就判错，额外编出荣誉仍须另查。
3. **蛋糕案**：输入仅提供暂停业务与水寒判断，目标却要求改温水及“书报恢复”。旧目标“书报恢复”本身也是制作错字；原文实际反馈为蛋糕做好、生意重新红火。这些后续信息必须单列明确来源，或只答输入支持的初断。
4. **走失侄女案**：输入包含作者平安与返回判断，目标又要求点评学员被害误断及“墓/库”纠正。需要原文完整角色和阶段材料；不能混成一个没有阶段标签的摘要目标。
5. **训练尾部杂项**：仍有2条图名作完整答案、3条一般规则答案夹带具体案例审计注。已逐条列ID，下一版移回索引/审计信息，不当作专业答案。
6. **检查过严**：例如“天芮”被严格天芮星槽位漏记，“取日干为失主”被严格名称槽位漏记。后验语义审阅认可这种明确表达，但不把所有提到关键词的句子自动放行。
7. **同权重入口不一致**：父比较入口与正式训练准备后的父对照，128题有81题文字不同；两个学习率组的正式父对照则逐字相同。源码显示比较入口未统一训练准备中的norm FP32处理；数值路径不同是需控制的因素，尚未在用户GPU重跑证明全部差异由此造成。下一版统一数值准备并保留重复对照。
8. **诊断覆盖**：课程有10条diagnostic，实际准备只取前8条；末两条年格、病药同宫诊断未跑。是运行范围遗漏，不是包里丢了两条结果。下一版全部执行。
9. **RAG检索与来源分类**：上层/下层表述没有归一到天盘/地盘；单干、六合等符号与“买卖”领域识别不全。另有明确的庚/戊定义被归为reference，知识模式会将其过滤。这些是独立于模型权重的检索问题；V5.3修正派生索引，并将实际检索评估与提供正确原文的评估分别保存。
10. **原分析索引不等于全部作者说明**：原书/RAG中部分“其实”“张志春按”“事后分析”没有进入旧1008条分析步骤。下一版按原章节精确定位，补33处来源解释或阶段标记及案例选段；不把学员误断写成作者最后判断，不修改原始步骤。
11. **学员初断与更正仍需分层**：女出租车司机等原案例的“分析步骤”同时记录了早先误断和后来的正确分析。下一版根据原文明确更正位置、原有修正标记区分阶段；37条更正之前的分段目标仅保留在整案复盘，不再当独立正确教学答案。原1008条记录不删除。
