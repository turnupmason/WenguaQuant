原12道训练原题的主项各阶段均保留，包括本人/同事取用、直接生克、同宫类型和明确规则结构的婚姻分支；微调后很多答案已改为较短表达，所以不能用逐字匹配判断这些主项。

有明确改善：高率E2能把旧字段题的本人改取日干、同事改取月干，父母的年干与年命也能分开；律师RAG题原来先说惊门、再否认书中有对应符号的错误尾句，在四个新阶段均消失。两星当前位置复述也更干净，原震宫/坤宫比较题四阶段都能说出木克土。

但这些改善还不能稳定迁移：

- **比较对象与属性。** 高率E2在艮、乾两宫关系中输出木克土，在震、坎两宫关系中输出木生火；有的句子先说土生金，后面却判艮受乾所生。两个对象直接给属性时能答对，改为先识别星或宫属性时仍错。
- **纠错任务。** 五道新标注题中，每个模型只有一题完整相符；水对火仍被认可成水生火，金对木被写成金生木。高率E2还先认可两水比和，再说同类相生。低率E1在土火题说出了火生土，但没完成前者受生及原标注的核对，另记部分覆盖。
- **条件否定。** 新题明确说吉门吉格不具备，低率E2和两阶段高率仍写成两项同时满足、可成；同一模型在旧JSON规则结构题却能答对。自然问法问婚事还缺什么时，四阶段仍漏吉门吉格或直接判成，即使原文已提供。
- **领域所问。** 改写后的放贷问题，高率把天乙生值符反答成值符生天乙；低率也有只复述方向、漏银行是否有利的情况。高率E2把杜门生日干的退役题答成准退；另一题杜门克日干虽说准退，却套用领导想留人的解释。
- **RAG中的具体名称和身份。** 高率两阶段将原文命名伏吟的戊加戊答成比和格；父亲本人问健康又答乾宫作主用神。低率在父亲本人RAG中只认出本人，未明确给出日干。已知父亲年干乙、年命癸的自然问法，高率又改答两干同属木或水，与字段任务不符。

这轮每阶段都有相同18条原检索证据重放，不是只测最低loss候选，也没有重新测试检索召回。上述错答发生时，相关原文已在输入中；不能归结为再加一本书就会解决。90条RAG存储答均未给内联[S编号]，引用格式与事实内容另记，未把缺引用直接当主事实答错。

## 课程回查与下一阶段边界

567训练核心实际有394种末回合教师文本，143条以先取本次起局开头；216来源单元保留，当前教师实际使用41单元、4条核心关联作者案例。门宫课间接展示了属性，星宫应用仍缺单独属性提取和跨对象绑定的充分示范；不能把目前阶段说成194案整盘教学已完成。

回查还发现6个训练首回合、6个开发题只写关系是父亲、母亲、同事等，未显式写谁代谁。这是需要明确人物关系的候选，不据此事后把原参考答改成另一种取用；原课程与评估输入继续封存。上表人物计数使用原来5道关系明确的字段题，不用这6个歧义候选抬高结论。

现有结果支持的修课方向：先抽取实际求测人与患者关系、当前对象和属性，再解释作用方向和本领域结论；基础属性、格名查询、宫间关系应分别教学。训练答案应保留本问需要的结论和理由，放贷不能只复述银行生借贷人，婚姻不能把未知或不具备改写成满足。相同事实需覆盖结构字段、自然问句和多轮变更，检查完整回答的一致性。

当前不新增古籍、不覆盖旧权重、不自动选择高率E2，也不自动启动更多epoch。V6.3父权重及本轮四阶段都保留；下一版是否继承某个V6.4分支，应在课程修订后用相同任务的完整回答比较，不能只看本轮0.147975的loss。模型错误回答只进入审阅档案，禁止作为古籍、RAG或教师。
