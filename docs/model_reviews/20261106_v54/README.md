## 读盘定位已经进步，瓶颈主要在作用关系

将18道整盘题拆开检查：父权重只有1题正确给出两星落宫；四个新检查点均为18/18两星落宫匹配。这里是该18题的定位分项，不代表所有符号、所有九宫盘均已验证，也不能推断之前移除单独定位课程没有代价。

新模型能够读取落宫，但经常在下一步把生克方向或前后对象弄反。例如可先正确写出某宫属金、另一宫属木，随后却写木生金。高学习率第2轮的18题中，有9题包含显式错误五行断言。相较只说“模型不会读盘”，应优先修复方向推导，同时保留读盘回放。

25道独立五行方向题也有“首词对、解释错”。例如题设前者水、后者土，回答“受克。土克水，是前者克后者”。前半句和字面五行循环正确，指代方向却错；原检查器将此题放过。补充检查单列显式指代矛盾，不改写旧分数；原14/25不能叫完整解释正确率。

## 格名有明显句式漏判，也仍有真实错误

高学习率第2轮的原格名检查只有4/14通过，但逐条读原答，有12/14包含正确格名。另2题未给出所问格名。许多漏判只是“是某格”或正确名称出现在第二句话，旧检查器仅接受有限首句形式。

高学习率第1轮13题出现正确格名，其中1题同时附上另一个格名；正确词出现不等于唯一正确答案。低学习率输出还有格名答对、后面添加错误主客/生克解释的情况。补充检查只记录名称、额外格名、显式矛盾，**不把关键词命中升格为整段语义通过**。

这两种检查问题都应在下一版修复：自然完整句不能漏判；正确开头也不能掩盖后文错误。本次没有临时放宽旧门槛或改写旧运行结果。
