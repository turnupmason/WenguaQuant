## 仍然存在的错误与退步

**星自身属性和宫属性仍会混淆。** 普通组五条、加权组四条星位组合答出现明确新增的固定星属性错误。例如已正确找到天心在巽宫，随后却说“天心星属木”。来源明确天心属金，巽宫属木；天芮属土也有来源。问的是两宫，不允许星本身跟着所在宫改变五行。普通组三条组合题还没有完成所问的宫间方向。加权组的方向较好，仍不能抵消附加属性错误。

**条件判词对，缺哪项条件却会说错。** 六个婚姻单轮题中，普通组五条结论与理由相符，加权组四条。题目已经给定乙庚两宫相生、明确没有吉门吉格，普通组一条却说相生/比和没有成立。加权组有一条一边说吉格未提供、一边又说两项条件都已满足；另有一条也错指相生条件缺失。

同一规则加上实际自身历史时，加权组先把“相生仍为真、吉格不具备”说成相生未成立；随后用户明确更新为两项都已具备，模型仍沿用旧错误说不能判成。其11回合中当前主要目标10条相符，2条有明确条件事实矛盾。普通组与父模型本组11个主要目标均相符；普通组一条“两宫相生与吉门吉格不具备”的合取表述有歧义，应明确缺的是吉格，不能当作已证实两宫相生为假。父模型在未知条件时也有“目前不成立”的未证实/已证伪措辞风险，均留在逐答注释中，不靠严格措辞漏判来制造进步。

**普通对话有实质退步。** 将“今晚不行，改明天”改成礼貌消息时，父模型回答自然，两新组都说“今晚不能改到明天。我改约明天吧。”前后矛盾。其余三个普通任务保留，包括事实抽取、库存计算和只保留第二步。这里只有四题，不外推成整个日常语言能力的准确率，但这条已对能力被损坏，必须保护。

**RAG附句仍可能添错。** 普通组有一答在只问丢失物取用时，正确说时干，却又无任何月令资料地添加“物与月令比和”；加权组有一答正确说银行有利，理由却把借贷人生银行改成克银行。加权组还把戊加戊称伏吟的原因泛化成五行相同，丁壬格名后又加不清楚的“这一层叫奇门”。这些附句没有因为前半句答对就放行。两新组在父亲本人求测题上选择本人规则正确，但省略了具体日干；记录为说明不完整，未误判成改取年干或乾宫。

18个旧RAG上下文均原样复检；主要所问大多保留，但三组都没有内联[S]引用。来源仍在问题与保存记录中，本轮未重新测试检索召回。没有拿这18题当完整多领域断案验收。

| 相同38个教师目标的统计 | 父模型 | 普通CE | 加权CE |

加权组确实更贴近声明关键位置的参考文字，软件也确实执行了四倍相对权重。可是其纠错、条件、多轮及部分RAG附句比普通组差，不能仅看0.3895比0.5593低就选它。

更有区分力的是：在正确的“对象属性→五行法则”教师前缀下，40个**生、克、受、所生、所克**目标位置，连原父模型都是40个top1正确；普通组和加权组也都是40个正确。这40是语言位置，不是40个独立问题，也不包括比和或判词样式。父模型自由答依然常错，说明给定正确前缀和自己组织整段回答是两件事。当前剩余失败常发生在前面的对象、条件或附句里，单独压低正确前缀下几个字的loss没有保证整答一致。

114个目标的真实token IDs、字符offset、所有关键mask及各均值均重新核对。原token记录的旧分段名称沿用V6.5先结论后解释的顺序，与V6.6先事实后的教师顺序不完全对应；本次**不将这些旧分段名当语义统计**，只按正确字区间计算。这个诊断字段问题未影响实际训练mask，冻结原记录没有事后改写。
