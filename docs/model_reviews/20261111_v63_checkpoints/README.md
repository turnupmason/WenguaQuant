## 课程回查

当前训练405核心、424监督回合，有213种不同教师文本。门宫关系128核心、直接五行75核心，合计203；另有人物48、主体切换15、同宫类型8、当前宫位16、婚姻分支18、领域分支22、六合角色15及来源对话60。只有4条核心关联原书案例，分别为手术、军官、失物发票和租饭店案；不是194案的整盘教学已经完成。

128条教师都重复“这里只判断门与宫的关系”。15条主体切换课里有5条实际上是本人→本人；其余也高度共用一句问法。部分任务在输入里直接写出规则结构或提示该用宫属性，模型在显式提示下答对，换正常问题就丢失目标。已有学习记录说明这些结构需要补，不能只增加同模板重复次数。

下一阶段教材验收逐项检查：

1. 人物取用先绑定实际求测关系，再读取日/月/年/时干。同一个人更换本人/代问时必须改变结论。已知年命与缺失时间字段分别说明，值不够时只说字段，不编造具体干。
2. 同一盘位分别问星本身、星与宫、两星所在宫，使用各自对象。程序核定的当前宫位继续作为事实输入。
3. 来源规则做成正常问句、带干扰资料、多轮主体变更和有来源的纠错；不复制已经暴露的开发题原文进训练。
4. 婚姻的未知、明确不具备、已具备分开，能否与日期分开；放贷、卖货、退役先明确所问一方和目标，避免受生一律说有利。
5. 每条教师只保留本问需要的理由。逐条删无关尾句，保留承担适用条件的限制，不能机械截断。
6. 原书案例按原盘、人物、当时已知资料和作者证据复盘，后续反馈单独保存。基础任务通过后逐领域增加完整案例，不能把后知结果放回提问时输入。

这份清单是下一阶段的修课合同，不是已发布或已训练的新教材。当前没有新增训练器或自动开启更多epoch，不能宣称课程或模型已经百分百正确。
