## 课程还存在什么问题

原书、7970材料、194案、1008分析、2049规则和46流程保持冻结。本次发现的是**课程切题和目标设计仍有遗漏**，不能推成古籍知识本身全部错误，也不能归因为还缺8本书。

346条局部推断中，279条在train，本次混合短训实际用了132条。这132条的目标正文按官方tokenizer分词：判断段含固定开头2002tokens，依据段11015tokens，判断段仅约15.4%。这是目标正文文字配比，不是精确梯度权重；但它说明增加推断题数时，大部分新增监督仍是重写可见证据。原答持续抄证据、复制尾部连接词，与只学会复述的风险一致，不能只增加epoch来掩盖。

至少以下边界要先修：

1. **可推结论与补作者原句没有完全分开。** 某军事史例遮掉两起特定历史事件，仅凭年干旺衰不能唯一推出具体事件名称。它适合有完整原文的阅读/复盘，不适合当作规则推理的唯一正确答案。上版过滤了新宫位、月令和部分未给年份，未拦住这类事件目标，是课程制作遗漏。
2. **具体数量与时段缺完整取数链。** 有的题要求精确到某小时区间、八至十二天或某个金额，但可见片段没有完整起局基准、尺度或中间取数步骤。原作者个案可以保留，切成局部课后不能丢前提再强判。全体346中有43条数值/时段候选需要复核，不表示43条都错误；已发现的问题在验证题里，不能未经检查就断言全部训练课也同错。
3. **同义表达被字面目标排除。** 有题已答物在家里、选九数或有希望，却因没有重现作者整句或缺证据而为0。应分别核对主要判断、证据完整性和可唯一推出范围，不将三者混成一个逐字通过项。
4. **阶段标签仍有粗糙处。** 一个出行案例明确是事故后的验证研究，却沿用“初断及按语”标题；预测未成案例的事后纠错也有遗漏。它们都仍是历史复盘，不能拿后来已知反馈当成事前断案成功。
5. **所问槽位不够明确。** “原文[S1]之后省了一项判断”仍接近补句任务，应改成直接问可见条件能支持的具体问题，并给必要的规则、主体和结论范围；资料不足时保留不足，不补造唯一结果。
