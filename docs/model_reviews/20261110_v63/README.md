## 仍有的错误及改教材方向

| 受控所问 | 实际观察 | 能说明的边界 |
| --- | --- | --- |
| 先代问父亲，下一轮换为父亲本人 | 两组所有已生成阶段仍取年干或乾宫，而非改用日干；部分还把出生癸补成起局年干 | 原题背熟不等于维护多轮人物状态 |
| 纠正“乾金生坤土” | 最后阶段虽出现坤土生乾金，又添“金克土”；中间阶段有金生土、土克金 | 正向判断与纠错问法需要分开教，不能只看到正确关键词就判通过 |
| 两个对象都是火 | 原题格式会答比和，自然追问仍混入火克金或自相矛盾 | 单纯换同义词数量不能替代不同问法结构 |
| 景火落兑金叫什么 | 大多读对门克宫，但漏门迫名称或错叫制 | 正确方向和正确术语必须分别核对 |
| 原始紧缩文字九宫盘 | 天英常回本位离宫、天任误读坤宫；明确给定坎/巽位置后大多能判水生木 | 当前课程不是完整读盘训练；应用应保留程序核定的当前盘位，不能让模型改盘 |
| 自然问婚事只知乙庚相生、缺什么 | 两组各阶段仍漏吉门吉格，即使提供原文，也常转去应期、年命等 | 结构化条件表的原题拟合，尚未迁移到自然条件问法 |
| 放贷、卖货、六合分领域 | 高率后期对借贷人克银行不利、时干克日干卖得快、跨领域六合角色有局部改善；低率并非每轮单调提高 | 有进展，也有阶段性退步，不能只取最高epoch |

训练课程仍是405核心/424回合的限定集合，不是两书所有完整案例教学已完成。个别课程题干泛问“缺出生年影响什么”，条件却已给出出生年命，需要明确这是一般缺失规则还是本题已知资料；这属于教学表述问题，不能改原书来处理。原194案、1008作者分析与全部原书资料都在；本轮没有新增真实结果。现有教师大量重复“这里只判断……”“不能……”等范围尾句，模型也学到了这些固定表述，部分还添出不恰当否定。后续修课应保留原书规则，扩大自然条件表达、多轮主体变更和有来源的纠错结构，减少无关尾句；不能把这些模型错答当教师或改原书来迁就回答。
