## 课程输入仍有一处要修

回查发现18个婚姻监督视图的实际可见前缀没有显式的婚姻/恋爱领域词；本轮7个固定诊断输入也有这一情况，包括三组原题/改问和一个最终条件单轮题。它们常只有乙庚宫关系、吉门吉格及本条分支，没有明确说明所问领域或展示本条规则。领域虽存在于数据的`domain`或任务元数据中，**这些字段没有送进模型**。

乙庚可以提示婚姻传统取用，因此这是输入自足性与教学范围的候选缺口，不是事后宣布所有原标签错误。当前原书、参考答和旧成绩均保持冻结；上表按原意图记录改问中无依据规则和自相矛盾，不能据这三题单独宣称已测正常明确婚姻问答的泛化准确率。

下一版应把领域、所问目标、采用规则和实际条件放在模型可见输入里；需要测内部规则记忆时也应明确领域，需要测条件执行时则提供完整适用规则。不能再让一个隐藏的字段承担前提。人物题此次已经显式写实际求测关系，这部分确实学得更稳定，值得保留。

## 下一轮训练的具体改动方向

继续保留V6.3起点及V6.5所有阶段，E2仅作为后续修复候选，不自动替换全领域模型。当前结果不支持重新训练官方分支或仅延长相同epoch，也不支持以再加古籍解释上述原题错误。

1. **先修课程可见边界。** 明确领域/所问目标/规则条件，原题、同事实改问与多轮更新保持同一证据，不把模型错误写进参考答。
2. **调整训练损失重点。** 对书中规则决定的方向、认可/改正、成立/不成立及主字段等关键目标位置单独约束，保留完整正常中文回答的训练。权重用于语言损失，不产生盘面吉凶分数；具体加权幅度仍须同父权重的短训对照验证。
3. **先核对事实，再组织自然回答。** 内部应区分实际对象、属性、施受方向和条件状态，再形成结论。五行与宫间有向关系可由已有确定性代码按原书核对，不能把正确法则与错误结论一起放行。这个协议尚未实现和实跑，不称已解决。
4. **验收同时保护已有能力。** 固定保留人物、星位和实际多轮，另外检查新问法、方向词和否定条件；分别看结论、理由、来源与领域结果，不只看平均loss，也不靠缩成单字来降低难度。
