## 已见的改善与退步

- 普通改写、库存15、只保留第二步基本保持正常。

## 这次还暴露了评估设计的限制

20题来源开发采用课程system，24题普通诊断采用另一个system，18题RAG又是第三个system。普通问法与JSON题面也不同。同火、金水等题在不同输入下表现相反，但现有结果同时改变多个因素，不能确定是system、表示方式、来源还是训练迁移单独导致。

部分身份开发题只问“该用哪个时间字段”，参考答案还列兼宫、出生年命；审阅不因模型未复述未被问到的完整答案就判错。更清楚的题面应直接问“哪个用神代表实际患者”，并说明使用问事时刻的四柱。没有给月干具体字时，可以答月干类别，不能替换成年干。

最关键的缺口是：本次没有已训练原题的自由生成，尚未确认是否连这些原题都能稳定答对。不能据loss下降就说数据已全部学会，也不能据此断言8B能力不足或必须再加古籍。
