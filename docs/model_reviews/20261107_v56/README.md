## 必须修的验收问题：正确表达被漏判

这一部分是独立事后观察，原检查结果、原自动决定不改。只核对题内已知事实、五行循环、施受方向与显式矛盾，不批准开放案例语义。

- **施生/生、施克/克未完全统一。** 题目用“施生/施克”，目标和检查多用“生/克”。如正确写出两宫属性、土生金、前者生后者，结论为“施生”，仍可能被漏判。
- **不应强制重复问题已有的事实。** “木克土，是前者克后者，结论克”在题内已给木、土时，不能仅因未重写“前者属木，后者属土”就当关系错误。
- **完整自然解释不一定先报规范关系词。** 两星落宫、双方属性、五行循环和方向都正确，但没有用首句或“结论：”报词，旧题可能不通过。
- **明确短答不应等于遗忘属性。** 问某宫五行，回答“属木”“属水”“属金”，应与错误五行分开。回答过短可以另列风格问题，不可当成事实全错。
- **未知年命的自然表达仍有漏判。** 如“取时干；出生年未知，暂不加年命”主要意思正确；“不补造相应宫位”则没有清楚回答年命边界，二者不能混为一种错误。

## 必须修的教材问题：同源不同摘录被误合并

在新增256条宫位练习中，用 `source_id` 单独去重，会把同一材料单元内不同的宫名、五行摘录互相覆盖。复核56/64宫对受影响，共224课程行（train168、development56）。例如输入问两宫，来源包中只保留后一宫的两条窄摘录，前一宫对应摘录丢失。

原文、材料单元、目标宫位五行没有被修改。这是**教师可见依据覆盖不全**的工程问题，不代表古籍规则错误，也不是全部模型错误的已证唯一原因；模型本可利用已学基础属性回答，但教材不应据此省掉承诺提供的来源。

下一版须按“来源单元+具体选择器/字面摘录”去重，并验证双方属性及规则都进入可见输入。已有全部完整原文继续保留，不迁就模型错误改书。本次冻结V5.6不热改、不覆盖旧分数。
