## 仍存在的真实问题

1. **方向或层级错。** 金克木的推导正确，开头却说“应改受克”；土生金的推导正确，开头却说“应改受生”。新整盘题也有位置与属性读对、关系或法则说错的情况；6道新整盘关系只2条完整一致。
2. **出生年命和起局年干混同。** 可靠出生年干为癸的代父问病回答“取年干癸”；本人问病有出生年时仍取年干癸；代母问病、出生年未知仍讲兼看年命。年干主用神、已提供的出生年命、未知出生年资料必须分层表达。
3. **漏多领域所问。** 问六合在婚姻、诉讼、交易中的三个身份，父权重完整列出，短训后只答婚姻媒人；另两个领域漏答，不能用其中一项正确认定整题正确。
4. **把结婚条件问成婚期。** 问乙庚相生是否一定能结婚，短训后答不能断婚期、缺时间依据。输入已经给出吉门吉格原文，相关三条训练教师也纳入本次短训，原文和课程并非缺失；它没有回答所问条件。
5. **一题重复到上限。** 本人考试、未知出生年、要求解释的结构化题，短训后重复同条考试规则至768tokens。不能因重复中包含日干一词而通过。这与另一道RAG考试短答正确可以同时发生。
6. **数对正确，附加解释仍可能错误。** 河图火二七，两边都附加“天二生火、地七成之”，而原文为地二生火、天七成之。父权重金四九另有同类天/地颠倒；数对5/5不代表整段解释全正确。
7. **格名漏答。** 原文里戊戊伏吟已经可见，但较长的类型边界问法下，短训后只复述天盘地盘或出生年区别，没有给出伏吟；简短实际RAG同名题又能答对。需要训练按所问选择结论，不能只增加记忆定义的次数。

这些误判需修复，但**不会消除跨领域漏答、婚姻题答非所问和重复输出**。本次停止仍有实质依据，不能只放宽门槛继续长训。

## 课程与训练原因：有证据的事实、待验证的解释

已经核对本次实际1024核心/1034监督视图、81920教师tokens的构成：案例20632、流程15038、领域规则7679、作者阅读1096、局部作者629，共约55%；身份4268、条件3953合约10%。课程按题数配平不等于按监督token配平，且阅读/复盘与按当前问题应用规则是不同任务。这个结构可复现，不证明它是所有错误的唯一原因。

跨领域六合有3条训练教师，本次抽到1条；婚姻条件3条都抽到。三个“婚期/时间依据”错误句在本次全量训练答案里没有逐字匹配，不能说它是直接复制某个错误教师。现象符合所问范围识别、条件应用、保留能力及格式迁移不足，需要相同信息、不同问法/目标的受控比较。

实际RAG提示仍普遍带“知识问答、没有本次盘面、不补造宫位或应期”的通用段落。对可直接从书中回答的规则题，这个缺盘提示没有必要；它可能强化无关的缺资料拒答，因果尚未经对照验证。下一版应区分知识解释、既有案例复盘和当前盘面预测，仅在真正依赖缺失盘面的任务触发缺盘追问。

只跑了65更新，不能判断增加轮数必然改善或这套数据已经饱和。相同提示原文充分而答偏，说明问题不只是“再收古籍”；loss更低也没有证明专业使用知识更好。完整192题的领域案例评估本次没运行，不能宣称完整断案能力已改善或已退化。
