## 实际发现的课程错误

8个多轮规格共48条派生记录缺少正确system角色：6个父/母/父母代问儿/女后切换本人题，以及2个疾病身份切换题。其中16条是本轮实际使用的基础train核心记录。

旧构造函数误以为人工messages已带system，覆盖了第一条user的内容；又把来源范围加到第一条assistant，并在后面的当前user位置重新写回最初的家属代问题，却保留“改为本人”的日干答案。这造成了提问身份与监督答案冲突。旧验证只查最后assistant和文本冲突，没有检查完整角色顺序，所以未拦住。

这是课程制作和验收的遗漏，不能归为模型没有学会。V5.4独立修复这批记录，保留旧V5.3源码、教材密文、模型和全部失败记录。新校验检查system开头、user/assistant交替、首轮与当前轮身份答案；完整多轮也拆出每个assistant训练片段，分别核对上下文长度。

其他真实错答包括：把同宫天地盘上下层替换成年干/月干；罕见格名反复答“地网天牢”；患者身份与天芮病神混淆；五行方向在128至256步仍未继续改善。这些问题不能靠放宽句式检查解决。

## 检查器漏判与实际RAG

旧“给定来源”49题中至少10条存在明确自然语言漏判，例如“本章取开门为法官”“取丁奇，因为……”、天盘庚的前缀、“最旺/旺”“门迫/迫”，以及正确格名后接逗号解释。另一方面，也有格名答对却把上下层解释错的输出。因此不能简单给原分数加10，宣称专业正确率已提高。

V5.4把事实槽位、显式推导冲突、引用成员/必需来源分开。自然句式可接受，错层、错误五行关系、未知引用仍失败；开放案例语义继续人工审核。字面来源范围核对到章节、原SHA和字符坐标，不能仅因同章出现同一词就认定有证据。

实际生产RAG探针18题的主要事实人工复核：**13正确、1条件部分正确、4错误**。18题所需原文均在当时可见上下文中；17题没有引用。唯一引用成员检查通过的回答把律师取用答成“律师”，没有答应取的惊门，说明有引用也不代表事实正确。4道主要错误涉及癸阴阳自相矛盾、母亲代女儿考试、律师取用、女儿代父看病的患者身份。婚姻生合条件题仍未完整说明吉门吉格限制。

这18题已揭露，之后只能作为**已见回归**。13/18是主要事实的有限审阅，不是完整断案正确率或新盲测。
