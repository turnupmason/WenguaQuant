## 学到了什么，哪里仍失败

1. **定位稳定，条件化基础题尚弱。** 17定位题全过；18整盘题的星位均读对。高学习率E2仍只有3/16给定位置关系、5/18整盘联合关系通过，说明“宫位→五行→施受方向→关系词”没有稳定连起来。
2. **原文规则组提取改善。** 忽略空格、引用编号和列表编号后，12题与目标内容相同分别为7、7、9、11。目标主要就是给定来源的摘录，而且这12组目标内容在train已有对应；不能把它解释成11/12未见盘综合断案能力。
3. **高学习率第二轮有回退。** 旧V5.3方向从E1的21/26到E2的23/26，仍在改善；但旧V5.4格名用V5.5检查器复核从8/14降到6/14，父权重为12/14。低学习率两轮为11/14。不是所有能力同步进步。
4. **RAG引用编号合规与证据支持不同。** 新192题中需要引用的129题包含来源练习和案例，不是129个独立现实检索事件。高E2编号检查121/129，并不代表每项结论均由该引用支持。
5. **原18题实际RAG，高E1更均衡。** 父亲代问取年干兼乾宫、本人考试未知出生年不补年命、婚姻保留吉门吉格，均能答出。高E2又把女儿代问父亲错取为时干，并在失主题重复“可靠”至1024tokens。低学习率两轮仍有未知出生年兼看年命、父亲错取时干等问题。四轮的六合跨领域题都没有按婚姻/诉讼/交易题序正确标注对应。
6. **作者局部结论推导仍弱，不能用复盘抄写替代。** 原告有调解意愿被扩大成被告胜；输入只有相对“今日”条件，却编出年月日；输入写婚后夫妻关系，输出却转成不会结婚。完整案例题中有作者分析和后来反馈，复述表现不能证明独立预测。

## 本次确认的课程边界问题

这些是课程制作问题，不能要求模型替课程补齐，也不等于古籍原文错误：

- **输入缺推导所需条件。** 对258条作者证据题运行有限来源条件筛查，发现13条候选（train10、development3），详见私有审阅表。例：考试题输入没有“伤门伏吟”，目标却要求据此解释未收集证据；选举题目标又含输入没有的门、神、干组合。筛查只有有限词型，13不是全部语义问题的精确总数，其余245条也不因此自动获准。
- **目标仍包含新的盘面事实，而不只是结论。** 按因果词切出证据和结论、验证字串属于原文，不足以证明输入信息完备。下一版须逐条拆分“已知事实、适用规则、所问结论”，不给遗漏条件留在答案里。
- **规则组拼接有重复。** 9个组的36条课程答案含同一长段重复（train18、development18）。原出处保留；教师自然答案应去除重复表达，并合并来源坐标。不能用删除整个规则或恢复人工评分来修复。
- **任务范围不够明确。** “推导本段所述判断”在一段有多项判断时不够聚焦；模型容易回答已经出现的地点/总结果，偏离需要推导的局部结论。病例等任务需明确问病位、程度、相对时间或哪项证据，而非允许任意续写。
- **训练与评估没有真正检验所有条件组合。** 域规则题经常只是同一问题加提示前缀；源族保留与新问法不是新事件。下一版需保留这类提取诊断，同时增设未见条件组合和前提变化题。

低语言loss受大量相同句式、复制依据和原文摘录影响。当前包不能单独证明优化器、8B容量或古籍本身是主要原因；也不能从低loss推断复杂断案已学会。仅增加epochs或问法数量缺乏依据。

## 权重处置与下一阶段建议

- 保留四个V5.5 adapter及完整checkpoint，原自动保留的V5.4父权重也不动。当前不批准任何V5.5检查点作专业成品。
- 高学习率第1轮step397列为**来源应用研究候选**，并非替换自动结果。它在原18RAG边界题较均衡，也没有该轮原18题的重复输出；高E2虽然提取更强、loss更低，仍有条件回退。低E2作为格名保留对照。
- 下一版先修证据边界、教师重复与任务范围；定位、宫位五行、施受方向、门宫命名继续保留复习。采用已核准来源事实作逐步核对，不引回旧人工吉凶分数。
- 先用同一修订课程比较V5.4父权重和V5.5高E1候选的短训，再由基础槽、条件反例、旧题保留与实际RAG共同决定长训。保留新阶段新优化器、同阶段checkpoint连续恢复；目前没有证据要求全部从官方基座重练。
- 在这些项过关前，不扩大参数搜索、不增加古籍、不无限loop。下一版本必须重新封定数据与新开发题；已审本批题仅作可见回归，不能冒充盲测。
