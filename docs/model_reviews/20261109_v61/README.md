## 原答中的真实改变

- **有改对的方向。** 芮在乾金、心在艮土的题，父答金克土，低率两轮改为土生金；心坤土、冲坎水的题，低率也改回土克水。
- **本人/代问仍未稳定绑定。** 女儿代问父亲且出生年未知，低率两轮却要求先看父亲出生年命。父亲本人来问、可靠出生年癸的题，两个第二轮都改成取年干癸，混淆实际主体和出生资料。
- **高率的个别对话更贴题，事实仍退步。** 第一轮回答六合在三个领域时，能直接列媒人、证人证据、经纪中介；但同轮又把金生水写成“水克火、火克金，所以水克金”，把相克错误地当作传递关系。
- **重复和摘抄没有彻底消失。** 两个低率轮次的三领域问题仍抄整段；高率第一轮的死门离宫题重复“门克宫，叫迫”至512tokens上限。第二轮未再这样重复，也仍未答对宫生门为义。
- **同一知识明显受输入形式影响。** 四个候选在旧开发题里都漏掉庚加戊的名称“值符伏宫”，两个实际来源包版本却都能答出；高率第二轮在短来源包里正确说地四生金、天九成之，在旧题里又写天四生金。不能简单说所有书本知识都遗忘了，也不能用来源包答对认定能稳定应用。
- **来源在场仍会混主体。** 高率第二轮回答“父亲本人求测”，先说取日干，最后又要求再按代问取年干兼乾宫，是本次RAG中的真实错误。

原检查问题也保留：杜门“归入木”是正常表达；当前银行凶分支已经选对时，引用另一条件下的吉不等于判断当前为吉。反过来，数值四九答对但附加天地生成为错、或比和与受生并列，也不能只凭关键词通过就认定整答正确。294份正式生成均附绑定原答SHA的限定读答注释；注释是已见结果的审阅，不是新盲测或独立专家金标。
