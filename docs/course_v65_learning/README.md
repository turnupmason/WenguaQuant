## 逐token指标的用途和限制

自由回答与逐token指标分文件保存。后者将标准回答作为已知前缀，做冻结forward，记录每个目标token的NLL、该前缀下的top1，以及结论句与后续解释的分段均值。审核题会分别列出标注是否成立、正确有向关系和五行依据；人物题列主字段、人物条件与出生资料；放贷题列银行结果与双方方向。段边界跨token时按token起始字符归属，完整offset保留。

低条件化NLL只说明在正确前缀下更容易预测标准文字，不能证明自由生成正确或现实预测概率；它不会触发自动通过、权重晋升或后续训练。结合原题/改问的完整回答，才能定位原题未学会、措辞迁移、关键结论词或解释续写中的失败。所有书籍来源、原参考答和错误模型尾句都保留。

真实Qwen tokenizer已检查70个固定题和38个完整教师前缀/字符offset；实际模型自己的多轮输入在每轮生成前重新核对4096上下文上限，超限拒绝截断。微型Qwen软件检查验证原生CE与目标位置NLL相等、无参数梯度、两种来源未变、实际模型历史拼接、恢复与Excel导出。这些不是4080实跑效果证明。
