# V6.6：修正可见前提，并对照关键位置的训练损失

本轮针对已经定位到的两项问题：部分婚姻课把领域放在模型看不到的元数据里；大段容易复现的解释文字掩盖了方向、否定和取用字段的少数错误。V6.5继承第二轮的原题604个监督位置仅7处不是正确目标的top1，却涉及6道错误结论。因此不继续只扫学习率或延长同一课程。

本轮是**真正的训练**，继承已学的V6.5第二轮step458；两组分别使用普通CE与关键位置四倍相对权重的CE。可见课程、初始权重、顺序、随机种子及学习率完全相同，先回答这个改动是否有效。旧V6.3、V6.5、原书及App起盘全部保留。

## 具体改动

- 婚姻题的领域、所问分支和“相生或比和，并且逢吉门吉格”的适用前提进入实际用户输入。未知、明确没有、已经具备仍是三个不同状态；每个多轮的首回合也有足够前提。
- 关系题用可核对的正常中文连接事实与结论，例如“艮宫属土，乾宫属金。土生金，所以艮宫生乾宫。”星自身与所在宫仍是不同对象。不会把参考答改成一个标签，也不保留724次相同的比较套话作为新目标。
- 保留1780个训练核心与24个开发核心。本轮分层选586个核心，展开615个完整助手监督回合，而非删掉其余资料。包括全部25种有向五行对、25对各一正一误的50核对题、25整段纠错、64有序双宫组合与8天心星自身对宫对照、64门宫组合、身份及条件变化、来源对话等。
- 原两书216材料、194案原划分及60来源对话保留。仍只有原课程中4条关联案例，不宣称完整194案均已训练；1080物理盘只贡献原先的八种星位旋转，不成为结果案例。模型错答、旧人工吉凶评分和新增书籍均不作为教师。
- 本地生成`local\course_v66_data\Wengua_V66_条件修复课程.xlsx`与`course.sqlite3`，包含完整来源、对话、关键目标字符区间及本轮是否选中。
