# V6.3 先验证课程是否真正学会

[V6.2新108答对照](../model_reviews/20261110_v62_learning/README.md)已确认adapter生效，但六道原训练题仍有基本类型、门宫关系、人物和条件错误。这轮实际训练使用同一套有来源的405核心、424完整监督回合；逐条保留用户输入、教师答案、来源摘录、194案例划分与原test边界，只把训练、验证、普通对话和RAG的SYSTEM统一为同一个正常交流提示。不新增古籍，不复制模型错答作教师，不把改写问法当新案例。

七投影结构与旧四投影不同，并且旧V6.2尚未通过原题学习检查，因此这轮从同一份封存的官方全零B矩阵初始化开始，不继承旧优化器或把未合格旧adapter冒充已学会的基础。两个学习率各自独立，均用相同初始化、课程、随机种子与轮数；同一组内保持优化器、余弦计划和RNG连续。中断重复启动，恢复最后完整封存checkpoint；旧文件全部保留。

数据由已校验的V6.2私有教材在本机确定性生成，不需要另下ZIP或新口令。所有用户/助手消息逐字与原包比对，来源和case_splits不变；只有SYSTEM与版本计划元数据变化。完整课程分词实测424回合最长1135tokens，20来源开发题最长650tokens，12原题、24既有诊断、18RAG均完整保留。配置上限4096不表示本轮实际训练了4096长度的完整样本。

每组先做4更新显存短测，短测权重不进入正式训练。初始化另对两种短输入做SDPA/eager、KV缓存/完整输入前向核对，不符合数值阈值便停止并保存记录。NF4、BF16、有界精确CE、融合注意力、80%分配器额度、微批缓存清理、独立worker、主进度监控继续保留。没有更换App排盘或任何术数规则。

第1/2/4/8轮的自由回答在该组训练完成后，逐检查点加载生成；屏幕显示`v63_answer_progress`就是作答评估。20题来源验证loss每轮记录，最多6轮连续无改善会提前停止。所有epoch adapter均保留，最多4份完整优化器checkpoint；语言loss候选只作研究候选，不自动覆盖模型。原题复现不等于举一反三，24既有诊断和18RAG也不是全新真实案件盲测，仍需要逐答审阅，不能输出经过验证的现实预测概率。

本机软件检查：358项stdlib回归、真实微型CPU七投影更新、8轮作答节点、GAS2新进程精确恢复、两率循环、官方RAG基线与导出路径通过。实际8B/4080显存和语义提升尚未验收；GitHub Windows/Linux检查结果应以目标提交Actions为准。

