## 教材及来源

841个训练核心、44个来源开发核心。514个V6.6核心的对话及教师原样复习；48个旧组合盘核心由更明确的对象任务替代，24个旧婚姻核心由独立条件组合替代。原1804个V6.6核心另行完整保存并逐项登记处置，原216材料及194案划分不变。当前仍含原来源对话中的4条关联案例，不宣称已经完整训练194案。

课程新增部分包括：

- **明确对象。** 天心星本体金、天芮星本体土、所在宫、宫本身属性分开记录。每回合在实际输入中明确比较的是星对星、星对本宫，还是两个宫；完整九宫星名、单字星名和程序事实卡三种输入都教学。星位只来自既有1080物理盘库中的八种真实旋转，没有引入原人工评分。
- **独立改变两个条件。** 宫间关系相生/比和、相克、未提供，与吉门吉格具备、明确不具备、未提供交叉。两项前提的真、假、未知是资料状态，不是吉凶分数或事件概率。一个条件不符合，不把另一个条件也说成不符合；一个条件未知，也不补造为有或没有。
- **连续追问。** 36个两回合核心只改变一项条件，另一项保留；另有多轮真假未知更新、对象层次及比较方向切换。历史教师必须按当时资料生成，当前监督回合有自己明确的条件/对象，不能由未来回答补前提。
- **纠错与未知边界。** 从书中定义自动构造正确/错误标注对照，不把模型错答作为教师。规则只说明某符号代表谁时，没有本次排盘或月令就不补出当前落宫、月令比和或具体日期。取用题明确同事、父亲或本人就是当前这一位患者，不增加另一位患者主用神。

保留原两书`shenqi`、`kaiwu`，不加入新书、模型回答或旧人为吉凶评分；本轮没有修改WenguaApp起盘、历法及原RAG索引。841是本轮定向教材范围，不是资料库只剩841条。

本地课程在`local\course_v67_data\Wengua_V67_条件修复课程.xlsx`及`course.sqlite3`，包含完整对话、来源原文与坐标、每个监督回合的对象/条件合同、原课程处置和案例划分。生成时按字节/逐格读回，不截断长答案或原文。
