## 教学变化

1. **分步衔接**：定位→宫位五行→谁生谁/谁克谁→门宫名称→条件→领域证据。给定位置题不再要求“只报关系词”。练习中的对象A/B是抽象对象，不把天干甲乙的固定五行随意改变。
2. **边界明确**：患者、病神、医疗用神分开；起局年干与出生年命分开。不知道出生年时可以先按已知身份分析，需兼年命再补资料，不是每问一句都重复免责声明。
3. **纠错带依据**：错误关系写在待纠正的用户输入中，正确答案仍来自原书生克规则；没有把模型错答转成古籍知识或正确教师。
4. **原书分组**：本组按来源段落编排，完整保留条件与例外；这种编排不等于作者完整断案顺序，不自动声称是所有门派、所有领域都适用的统一流程。规则与案例保留书籍、章节和原SHA。
5. **引用不靠固定编号**：部分来源包置换S编号，文字原样保留，答案与引用元数据同步变换。置换课是来源包增强，不谎称是生产检索原封不动的输出。

原RAG索引不改，V5.5查询按领域问题可选取新的原文字面规则组；没有把手写答案或模型输出灌入原书索引。按时间起盘仍调用现有确定性程序，模型不编盘。

## 训练循环与恢复

结构保持已经在本机跑通的Qwen3-8B固定revision、NF4 QLoRA、r16/alpha32/dropout .05、q/k/v/o、batch1×累积16、4096上下文、128 token分块loss及已验证的efficient attention。没有切回高显存的全量logits或math attention。

两条路线都从同一step134开始，学习率 **1e-5、2e-5，各2轮**。新教材重建优化器和cosine计划，同组epoch之间保持优化器连续。每25更新及完整epoch保存完整checkpoint，保留独立epoch适配器。

对方向练习回放3次，给定位置、门宫、条件、规则组各2次，其余1次。这个是训练配比，**不是人工吉凶打分或新知识数量**。最终4738个train核心含多轮assistant拆分，展开与回放后为 **6338个训练片段/轮，397更新/轮，每学习率794更新**。进度条的794是更新步数，不是794个epoch。耗时由本机速度及评估决定，不承诺固定几小时完成。

全部6000个唯一assistant片段已用缓存官方tokenizer逐一检查，最大3107 tokens；原答案未截断。新192题及旧回归题完整保留。16步压力测试只作内存验证，不把其权重用作正式训练父模型。

默认48小时执行预算，临近预算保存后暂停，再执行相同命令继续。断电或中断可能损失最后一个完整checkpoint之后的少量更新；恢复时检查数据、代码、模型、优化器和随机状态合同，不从半个checkpoint冒充继续。

## 每轮评估与模型选择

新192题固定包含：九星五状态5、方向25、读盘定位17、给定位置方向16、整盘关系18、门宫16、属性8、身份12、条件16、格名16、规则组12、作者证据12、19领域案例19。九星状态只是这五道来源条件练习，不代表所有旺衰、空亡、墓刑都已获验证。

12组规则评估优先覆盖疾病、失物、工作、求财、婚姻、考试、胎产、出行、走失、诉讼、刑案、天气，使用实际RAG来源包。开放规则组、作者证据和案例语义仍保留原答人工审核。

新检查器接受“是某格”和第二句话出现的明确格名，也拦住正确开头后的错误循环、前后对象倒置、同干相克、未知出生年使用年命、多个候选格名等明确问题。否定“不能保证一定成功”不会被当作肯定承诺。它仍是有限事实与矛盾检查，不能冒充完整专家语义裁决。

每条路线先检查同一父权重；每轮还保存原封不动的V5.4旧128题、V5.3旧128题、原18道实际RAG。旧版评分按原版保留，同时单列新检查，不覆盖旧成绩。旧题与新课程变体已见，不称新的现实盲测；案例继续按原事件家族划分。

自动门槛包括定位≥.90、给定位置方向≥.85、方向≥.90、门宫≥.80、身份/条件≥.85、格名≥.80、属性≥.90、九星状态来源事实≥.80、整盘关系≥.80、引用≥.90；同题相对父基线下降不得超过.05，并复查旧方向回退和未知年命误用。只推荐人工审阅，不自动称专业模型或上线模型。

两组全部结束状态是 `complete_review_required`，不是运行崩溃。即使新候选未通过，也保留全部答案与旧父权重，不把最低loss当作最佳。
