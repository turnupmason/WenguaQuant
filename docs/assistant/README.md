# 本地问卦入口：先检查真实使用，不再追加训练循环

最近一次完整审阅里，父模型、V6.7第一轮、第二轮的清楚整答分别为143、142、140／161；部分星位题和条件追问有进步，纠错、来源应用和普通对话仍有退步。验证loss下降不能证明整体断案能力提高。最近这次短训只有4条关联案例课，194案目录保留不等于194案都已完成整盘断案训练。此前把小题修订、语言loss和实际使用能力混在一起，是推进方式的问题。

另有实际接线缺口：V6.7入口只有训练、检查和导出，旧问答入口绑定V6.0的模型目录；旧领域流程检索主要由知识模式中的“流程”等字眼触发，实际按盘问事没有同等入口。新代码独立放在 `wengua_assistant/`，不修改冻结训练器、原排盘、课程或任何权重。

在 **PowerShell** 中运行：

```powershell
Set-Location "$env:USERPROFILE\WenguaQuant"
git pull --ff-only origin main
.\start_wengua_assistant.cmd
```

浏览器自动打开 `http://127.0.0.1:8767`。这是推理入口，**没有训练任务**。沿用邻目录WenguaApp的 `local\qwen_env\Scripts\python.exe` 和已有8B缓存。只在缺少系统时区资料时安装tzdata，不升级Torch、Transformers、PEFT，不下载另一套模型。原有历法支持离线起局，不强制安装可选的Swiss Ephemeris。

默认现在是官方原模型的“普通对话”，使用简短通用提示，不检索古籍、不起局、不强制引用。它用于直接查看中文理解、表达和实际连续追问，也可显式选择V6.7实验权重作同提示对照；切换模型时新开对话。原来的“古籍知识问答”和“按时间问事”仍保留来源规则约束，专业问题使用这两个入口。这次没有重新训练、替换或删除任何权重，也没有据此宣布语言能力已恢复；实际8B质量仍需要用户本机输出验证。

23:00至23:59现按两书的“子初23点换日”起局：原书23:45按次日子时、23:30按次日子时的干支与局数已复现。显示和保存的真实时间不改，只有干支日归属前进一天，时干按该日五鼠遁计算；节气、年柱和月柱仍用真实交节瞬间。修复只在新入口的独立适配层，其他时段逐字复用原程序回执，原App的23点拒算及所有冻结代码保持不动。来源坐标与原文SHA见 `data/assistant/late_zi_sources.json`，不把案例后续反馈加入问事输入。

可以输入自己的问题、选择领域和起局时间，或切换到不需要盘面的知识问答。时间默认取电脑所在地，另可选择北京；显示为当地日期和时刻。程序仍调用原App的历法、定局与排盘函数，拒绝不明确的夏令时重复时间、无效时间和原程序没有解决的边界，不让语言模型起局。

模型可选官方缓存Qwen3-8B，或V6.7第一轮step113候选。候选的配置和权重SHA必须与已审阅的实际文件一致；未称其为全领域最佳。切换模型和时间需要新开对话，避免把另一模型的回答当作本模型历史。两种选择都走同一问答/RAG流程，每答使用独立GPU进程，沿用已验证的高效注意力路径和80%分配上限，生成后进程退出；这不构成在当前云环境做过真实8B显存验收的声明。

新检索器从原两书的已核原文选择器中排序，按实际领域补取用、关系及条件相关原文，无需用户必须说“流程”。六个常用领域有专门的检索阶段，其他登记领域使用该领域原书取用检索；阶段查询只是搜索词，不是新编专业规则。不再让通用五假九遁在疾病应期问题里优先，也排除无关刑侦示例。来源规则组仍是原书片段的集合，**不声称已经自动编译出所有领域的完整专家判断程序**。

源文按完整选择器放入上下文，不截掉一条规则中的条件。模型的总上下文仍为4096；页面展示本轮实际可见来源、跳过的整段及输入预算。长对话超过预算时要求新开，不静默截掉用户条件。旧问题及本模型原始回答逐字保留；旧来源块根据当前问题重新检索，不把上一轮模型回答升级成原书证据。每轮引用有独立编号，旧编号不会被悄悄赋予另一段内容，原文内部的标记也不改写。

“补充资料”中的未填写、明确知道、明确不知道是不同状态。不填写出生年干不会覆盖用户在问题里给出的年命。四柱甲干的定位使用原程序的完整干支旬首，不能把所有甲都套用时柱旬首，也不补造未知出生地支。盘面显示星、携干、地盘干、门、神的原始位置，没有引入旧人工吉凶分数。

“原书案例”列出全部194案、1008条分析的原有来源登记，显示原书转录盘、各阶段片段、学生初断/作者更正等已存标记。它是独立的原文查看器，不调用模型，不把后续反馈送入新预测，也不改变任何封存案例或最终测试的划分。

模型回答原样显示。引用编号及有限星位断言核对不等于完整语义核准，也不能证明疾病或失物结果的现实准确率。没有足够资料的应期和百分比仍不能编造。新入口是把实际问答链路接起来，**没有据此宣布权重能力已经提高**。

完成自己的对话后，点击“下载对话结果ZIP”。包内只有这次对话的输入、原始输出、实际盘面与所选来源、代码/模型版本、日志；不带模型权重或整本书。文件留在电脑上，由用户决定是否交给后续审阅。结果绝不自动加入RAG或训练教材。
