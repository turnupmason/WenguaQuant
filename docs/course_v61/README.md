# V6.1 正常对话与条件应用续训

这是针对 V6.0 已确认的课程问题制作的小规模修复实验。教师先回答所问，再解释必要条件；原文作为输入证据或独立来源记录。不是把旧 V6.0 重新执行，也不声称两书全部课程已重编完。

## PowerShell 启动

```powershell
Set-Location "$env:USERPROFILE\WenguaQuant"
git pull --ff-only origin main
.\train_wengua_v61.cmd
```

首次恢复新教材时，输入此前教材的64位口令。无需另外下载ZIP或安装依赖，继续使用相邻 WenguaApp 的 `local\qwen_env` 和已缓存的 Qwen3-8B。

- 继承已审阅的 V5.8 E1 step97；不继承未通过留存的 V6.0 候选。
- 学习率 `3e-6`、`1e-5`，每组两轮，共四个轮次候选。两组从同一权重出发，各自新建优化器；同组两轮不重建优化器。
- 320个训练核心，324个逐助手回合视图。正常对话显式复习3次、人物条件复习2次，合计486视图/轮，每轮31更新、每组62更新。复习不是新增知识或独立案例。
- 60个正常对话核心来自32组另行编写、逐条核对出处的教师；区分有参考原文与无参考原文。含四个作者案例片段的推理，未把片段当成新盘完整预测。
- 其余为明确方向、门宫名称、真实盘读取、人物与出生年边界、天地盘顺序；答案均重新组织，不把原文整段充当教师。没有旧人工吉凶分数或模型错答教师。
- 对话和人物题约占监督token的56%，用显式复习调整比例，避免案例原段复述再次占据主要监督。
- `4096`上下文、r16/alpha32、dropout0.05，保留已跑通的有界损失、融合注意力、80%分配器额度和进程隔离。最长实际训练3044tokens，完整输入/目标不截断；不以本轮数据宣称所有4096负载都已验证。
- 每10步保存，轮末另存权重；中断后重复同一命令，自动选择最后完整封存检查点并恢复优化器、调度器和随机状态。
- 每轮40道既有分层开发题，另对每组语言loss候选生成18个既有RAG主题，第一组另生成父权重的同套18题。它们已被历代开发观察，不宣称新盲测。旧有限检查只作诊断，全文回答保留供复核，不自动把语言loss最低者晋升为专业最佳。

两组完成后状态为 `complete_review_required`；原保留权重不被覆盖。`research_nominee.json`只是语言loss提名，不能据此认定模型已进步。原7970材料、194案、1008分析以及其他版本课程和起盘代码保留。

## 数据审阅

新教材独立保存在 `local/course_v61_data/`：完整Excel、SQLite课程库、来源与教师JSON、构建配方和校验记录。原书数据库和当前RAG索引均不改。本版只使用原train锚点制作训练教师；原validation用于开发对照，原test继续封存。32组教师原候选与模型错误审阅是不同文件，本版显式提升前者作训练练习，后者没有读取或回灌。

云端可验证软件继承/恢复和源数据边界；真实8B效果仍须依据本机生成结果判断。
