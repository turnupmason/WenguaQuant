## 四项修订

1. **关系方向与结论一致。** 增加75条有明确A/B方向的教学任务；同时检查关系名称、实际五行方向和所指对象，不能用后面正确的法则掩盖开头相反的结论。不允许把匿名宫位自行解释成未给出的星、干或人物。
2. **人物与年份条件逐轮核对。** 主用神、辅助宫、可靠出生年命、起局年干分别记录；每个助手回合单独检查。书中参考案例的年份不能冒充当前人物出生年。知道年干不等于知道日干、时干。加入20组同一来源规则下的条件切换对话，明确下一轮哪些事实替换上一轮事实。
3. **从可见证据作判断。** 346条局部推断课覆盖19个案例领域，包含原23条课的目标修订；只从原作者同一阶段、已给条件中选取判断，不用模型生成教师。排除要求猜新落宫、月令、出生资料或后续反馈的自动推断候选；完整原段与原案例仍保留。回答给出所问判断和依据，移除“待补”训练目标；整案复盘补回对应原阶段的分析依据。所有1008条作者分析都有教学、阅读、归档或原test封存的明确处置和关联记录。
4. **教材重叠与评分边界。** 领域规则、流程答案按完整句去重，处理嵌套序号；原书材料及案例阶段不改写。修正“应改记”后仍方向相反、受克对象颠倒、未知年命兼用、编造天地盘、领域顺序交换等漏判，同时接受有明确所指的正确自然表达。原V5.8评分保持冻结，新检查的事后诊断不能冒充模型能力提升。

回答按题目要求的顺序组织；未指定时先回答结果，再说明必要条件和证据。知识题不附加无关的缺盘声明，局部题不展开到其他阶段或后来结局。没有强制每题重复四个固定标题，也不把正常分析压成一个词。

## 有限训练loop与保留旧能力

2. 父权重及每轮各用相同112题与36个RAG来源包检查。**逐题保护父模型已通过的事实、完整条件和所需引用，不允许用其他题新增的正确项抵消丢失项；还须至少新增一项完整答对。**
3. 通过后，继承选中的短训权重，完整应用课程1轮，共346次更新；同样比较新阶段父权重，完整阶段退步则保留已接受的短训候选。

5. 每25次更新及轮末保存完整checkpoint；暂停后重复启动命令，恢复同一阶段优化器、调度器和随机状态。跨教材继承adapter与阶段内`resume_from_checkpoint`严格分开。
