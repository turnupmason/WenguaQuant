# V5.7：来源完整、条件对照与混合继承训练

本版先修课程和检查，再交付训练入口。前几版的明确遗漏不能归因于“模型还需多练”：同来源 ID 的不同摘录被误去重，部分题目缺少双方宫位依据；身份和出生年条件不够显式；评分把正确的自然表达漏判，也可能忽略最后一句的矛盾。V5.6 的短训只覆盖部分基础技能，完整案例训练没有启动。旧材料、旧成绩、失败记录和所有权重保留，本版不改历史分数。

版本化修复如下：

- 来源按 `(source_id, quote)` 去重，关系题明确展示双方宫位属性及有关生克原文，逐条检查必要摘录确实可见。读取整盘的题目同时检查九宫完整性及目标星实际位置。
- 角色题明确实际求测人、所问对象、可靠出生年是否已给出。新增本人/代问、未知/已知年命、撤回错误资料、角色切换、多用神同宫及资料不足追问。28条多轮对话全部检查每个助手回合的对应身份，分别生成训练目标。
- 原作者分析保留完整同阶段原文和来源坐标，不截出失去条件的单句。903条完整原段阅读，8条仅有讲话引入的原文只作上下文阅读；23条限定局部判断与193条案例来源课程保留。它们是作者案例教学/复盘，不宣称全部是未见整盘独立预测。
- 判断事实、解释充分程度、引用成员和开放语义分别记录。短而正确的属性或关系不因未重复题干而判错；错误五行、主客方向、出生年、人物取用、数字或相反的尾句仍失败。开放作者案例不以关键词命中率冒充专家验收。
- 新40条人物条件教师和18题评估均实际调用原两书检索器；缺少必要原文时不把教师段落偷偷补进检索结果。保留原App起盘接口，模型不负责计算历法和起盘。新增系统提示后重新计算真实token预算。

## 有限训练与分层评估

默认继承已审阅V5.5高学习率第一轮step397，模型文件SHA：

`fe22c4ba1efbf6aba198eb3f68725e4f2d155387f3de619f138578db99ce93f5`

使用已留存的V5.5路径，绝不覆盖旧权重，也不偷偷退回官方模型从零开始。V5.6没有通过晋升条件，故不直接把它作为已证实优于父权重的基础；这不代表认定所有V5.6技能都更差。

固定Qwen3-8B、NF4 QLoRA、r16/alpha32/dropout0.05、q/k/v/o、4096、梯度累积16、LR1e-5、warmup0.05。沿用已跑通过的有界loss和融合注意力，禁止长上下文math fallback；每个GPU单元用独立子进程，保留请求、回执、心跳、注意力/loss路径和显存采样。

1. 混合试训：1,024个独立核心，1,034个助手监督视图，65次更新/1轮。含96案例、48领域规则、48流程，以及作者阅读、定位、关系、身份和条件题；不是只练基础再把案例无限挡在门外。
2. 同问题、同父权重比较64道固定事实题和18题实际RAG。试训门槛检查能力留存和输出完整性，允许研究课程继续学习；它不是专业通过门槛。任一原本正确的RAG事实/条件退步，或者事实类别明显退步，则停下保存结果供审阅。
3. 通过留存后，继承试训权重，开启新阶段优化器，完整课程训练2轮/698次更新。阶段内优化器、调度器及RNG连续，每25更新及轮末存完整checkpoint；保留4个完整优化器checkpoint和每轮adapter。
4. 每轮只生成固定64题+18实际RAG，保留父权重的同题对照。同权重、同题、同目标、同token预算的答案可以带SHA证明复用，防止反复加载和生成。
5. 最后仅为选出的研究候选生成完整192题（其中64题复用），并一次性检查旧V5.5的192题及原评分。精确匹配已审阅V5.6上传包中的V5.5原父权重旧192答时直接复用；缺失或SHA不符就重新生成一次。旧观察不进入训练。

正常完成两阶段，在旧父权重观察可复用时约648次常规回答，另有短测回答；未缓存时额外生成192答。重试、暂停和人工复核另计。最终结果不以最低loss单独定专业最佳；新事实门槛和开放案例审阅独立保存，`production_enabled=false`。这些开发题及既有作者案例不称新的现实盲测。

## Windows PowerShell启动

用户设备已实际识别为RTX4080 16GB；本地保留之前可用的 `WenguaApp\local\qwen_env` 和8B模型缓存。两个仓库同级。

```powershell
Set-Location "$env:USERPROFILE\WenguaQuant"
git pull --ff-only origin main
.\train_wengua_v57.cmd
```

首次恢复提示时粘贴此前64位教材口令；不用手动下载ZIP。默认24小时预算，到预算边界会保存完整checkpoint。暂停或中断后重复同一命令，自动恢复最后完整checkpoint；不要把旧版本checkpoint强行当成同阶段优化器。显式参数 `--resume-from-checkpoint` 只允许本次V57输出目录内的已封存完整checkpoint。正常结束或门槛未过不会再自动无限训练。

结果：`local\course_v57\run1\results.html`，状态见同目录 `run_status.json`。`needs_course_review`表示混合短训的留存检查未通过，完整阶段未启动；`complete_review_required`表示有限计划已完成，仍需审阅。停止状态和原答均保留。

导出结果（不带模型权重）：

```powershell
Set-Location "$env:USERPROFILE\WenguaQuant"
$review = Join-Path "$env:USERPROFILE\Downloads" ("Wengua_V57_review_" + (Get-Date -Format "yyyyMMdd_HHmmss") + ".zip")
& "$env:USERPROFILE\WenguaApp\local\qwen_env\Scripts\python.exe" -X utf8 -m wengua_course_v57 export --archive $review
explorer.exe /select,$review
```
